## Appendix A — the ledger read that produced §3.2 (run over BBX's tree, bbx-26)

```python
import re, collections
t = open('docs/gotchas.md').read()
parts = re.split(r'(?m)^(#+ G(\d+)\b.*)$', t)
entries = [(int(parts[i+1]), parts[i+2]) for i in range(1, len(parts), 3)]
LEAD = re.compile(r'(?:Re-anchors:?|Rules? re-anchored in fact:)\s*')
REF = re.compile(r'BBX-\d+|§\d+(?:\.\d+)?|\[BBH-\d+\]|\bR\d+\b|\bD\d+\b')
def strip_parens(s):
    out, depth = [], 0
    for ch in s:
        if ch == '(': depth += 1; continue
        if ch == ')': depth = max(0, depth-1); continue
        if depth == 0: out.append(ch)
    return ''.join(out)
table = {}
for n, body in entries:
    refs = []
    for para in re.split(r'\n\s*\n', body):
        p1 = para.replace('\n', ' ')
        for m in LEAD.finditer(p1):
            seg = strip_parens(p1[m.end():])
            seg = re.split(r'\.\s+(?=[A-Z*])|\.\s*$|:\s', seg, maxsplit=1)[0]
            seg = seg.split(' — ')[0]
            refs += [r for r in REF.findall(seg) if r not in refs]
    table[n] = refs
by = collections.defaultdict(list)
for n, refs in table.items():
    for r in refs: by[r].append(n)
print("entries:", len(table), "with no list:", [n for n, r in table.items() if not r])
for i in range(1, 31):
    print(f"BBX-{i}: {len(by[f'BBX-{i}'])} {by[f'BBX-{i}']}")
```

The lead is case-sensitive on purpose: lower-case "re-anchors" and
"re-anchoring" occur in prose (G8, G9, G13, G53) and are not lists. The list ends
at its sentence, at a colon, or at an em dash; an explanation in parentheses is
never read. Its first-line-only predecessor reported 12 rules with no incident
(G61); a paragraph-to-the-end variant over-read explanations. Run again over the
ledger once G61–G65 were written, it read a lead word QUOTED inside G61's prose
(G17's lead and first id, in quotation marks) as a list and credited BBX-24 and
BBX-26 to G61, which names neither; G61 was reworded before its commit, and the
five new entries were then required to add exactly the references their own lists
state. A tool built from it (K4) carries the controls of §8 that those three
failures define.
