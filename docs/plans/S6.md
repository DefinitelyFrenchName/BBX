   reference check is scoped by the documents register's shapes: history and

## 5. The design, contract by contract (proposal; R59–R65 decide)

**K1 — Executable controls (R29 as ruled; R60).** Rebaseline bbh to `e7d6767`
by R28's procedure (every F row measured on the D20 override before the move),
then lift bbh's form — the mode entrance, the classifier's four verdicts,
`--exec-controls`, the sweep's `<gate>@<name>` — into BBX's runners, keeping
BBX's python reader as the one reader of a header (R30). A gate that calls the
mode entrance is EXECUTED, and its REFUSED is a dead control; a gate that does
not is counted on the screen as self-reported, never as proved. The screen's
line becomes `controls: fired N / declared N; executed N (honoured N, lies N,
refused N, died N); self-reported N`, and the slice is not DONE while a
registered gate is self-reported.

**K2 — Controls over the whole tree (the slice row's readout).** The screen
counts every control declared under `gates/`, and names the gates that did not
run and their tier in G57's form: `declared on disk 182, in this run 179
(file_census: release scope, 3)`.

**K3 — The defaults register, checked (R61).** `bbx defaults --check` over

**K4 — The documents register (R62).** `docs/documents.toml`, in the TOML subset
